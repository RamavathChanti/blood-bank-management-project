# Submission setup and interface index

Teaching model, not clinical software. All data is synthetic. The editable
college package and evidence live in the workspace's `_ai_context/submission/`
and `_ai_context/STAGE_15_EVIDENCE.md`; application/tooling remains here.

Use Node 24.x, `npm ci`, `npm run build`, then `npm run start`. The local labs need
no provider credentials. `/try` is the in-app guide. `npm run submission:offline`
builds an internet-independent simulator into the submission package; it uses
the same domain/UI components and requires only Python 3/browser at runtime.
`npm run submission:record` records the production local application and writes
timings/transcript/video. The report/slides exports and allowlisted ZIP are
generated by `submission:documents` and `submission:package` (Python required; document export also uses installed Playwright Chromium).

## Environment names and safe defaults

`.env.example` is the complete name/default catalogue. Keep values out of reports,
browser recordings and source archives. No secret is necessary for local labs.

Never enable a feature merely to make the presentation claim appear complete.
Configure isolated synthetic services and repeat their acceptance before use.

## Validation and limitations

Use `npm run lint`, `npm run typecheck`, `npm test`, `npm run test:integration`,
`npm run test:workflow`, `npm run surge:rehearse`, `npm run build`,
`npm run test:cache`, then `npm run test:e2e`. Workflow/cache runners manage their
own local services. Build before cache/browser tests and keep port 3000 free.
For hosted smoke use the exact origin and `PREVIEW_REQUIRE_LIVE=1` with three
privately supplied authenticated states as described in the release checklist.

The source archive excludes node_modules: install dependencies before source
replay. The standalone offline bundle is prebuilt. No Git command, account
mutation, hosted deployment/reset, email or publication is required for package
generation. Known limitations include synthetic/clinical simplifications,
single-seed policy results, local service timing, mocked auth in integration,
unverified hosted region/CDN and physical-device rehearsal. Read the stage
evidence before presenting any claim.
